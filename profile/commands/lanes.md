---
description: 并行车道：把任务拆成互不依赖的车道，同时派出多个 lane-worker 加速
argument-hint: "要并行推进的任务，例如：同时实现三个 API 端点"
---

<user_input>
$ARGUMENTS
</user_input>

1. 先判断是否真的可并行：子任务之间没有文件重叠、没有先后依赖、验收各自独立。不满足就老实串行，说明原因。
2. 拆车道：每条写清目标、允许改动的文件、不要碰的文件、接口契约、验收标准。
3. 在同一条消息里同时派出多个 lane-worker（需要完全隔离时用 worktree-worker）。
4. 收齐结果后：检查改动是否越界、接口是否一致、是否有文件冲突，再跑一次整体检查。
5. 汇总每条车道的实际改动与验证结果。

不要为了并行而并行。共享接口只让一条车道负责。
