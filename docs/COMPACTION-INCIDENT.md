# 低上下文用量反复压缩：修复与运行验收

日期：2026-10-27。修复提交：443d2ef。保留 v3 配置层设计。

## 原因

profile 中的 `autoCompactWindow: "auto"` 被原样写入运行设置。WorkBuddy AI 5.8.4 的原生 `/autocompact auto` 实际通过删除字段恢复自动模式；阈值计算会直接使用该值。

字符串进入 `Math.min("auto", modelWindow) * threshold` 后得到 NaN，`inputTokens < NaN` 恒为 false，因而绕过低于阈值时的返回路径。原先的校验仅检查值非空，测试也错误地断言字符串存在。

## 修复

- profile 仍可用 auto 表达意图，安装器将其转换成删除运行字段。
- 数值覆盖只接受正的 JavaScript 安全整数，排除布尔值、字符串、非整数与非法范围。
- 运行校验接受字段缺省或合法数值；非法值不会因应用回写而降级为警告。
- 回归涵盖旧错误配置修复、重复安装、类型边界和回写后的校验失败。

39 项回归、25 项本机静态检查和两项独立代码审查通过。
