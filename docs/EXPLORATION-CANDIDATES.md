## 本次已批准：自动压缩配置修复
5.8.4 原生 `/autocompact auto` 删除 autoCompactWindow 字段。运行时将该字段直接代入 `Math.min(setting, modelWindow) * threshold`；字符串 auto 产生 NaN，`inputTokens < NaN` 恒为 false。
本机 2026-10-27 11:52:08、11:53:06、11:54:08 日志分别在约 39945、42925、43894 / 1000000 token 时触发 emergency-auto，与此错误一致。
因此 profile 可保留 auto 作为安装指令，但运行配置必须缺省；数值覆盖须为正的 JS 安全整数。测试需覆盖历史错误配置迁移、重复安装及校验拒绝，不仅断言字符串被写入。
本机错误字段已备份后移除。修正后原安装实际运行 7 分多钟，64 次预算检查从 35,241 增长至 166,833 token，0 次压缩启动；详细对照与未覆盖路径见 [压缩故障验收](COMPACTION-INCIDENT.md)。
