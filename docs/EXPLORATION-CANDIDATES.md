本机 2026-10-27 11:52:08、11:53:06、11:54:08 日志分别在约 39945、42925、43894 / 1000000 token 时触发 emergency-auto，与此错误一致。
因此 profile 可保留 auto 作为安装指令，但运行配置必须缺省；数值覆盖须为正的 JS 安全整数。测试需覆盖历史错误配置迁移、重复安装及校验拒绝，不仅断言字符串被写入。
