# 脚本文件规则（读写 .ps1/.bat/.sh 时生效）

- `.sh`：必须 LF 行尾。写完 `bash -n <file>` 检查语法。
- `.bat/.cmd`：纯 ASCII + CRLF，顶部 `chcp 65001`；不写字面中文路径，用 `%~dp0` 和环境变量。注意：本机会话沙箱拦截 cmd.exe，`.bat` 只能写，不能在会话里运行验证，要说明"未验证"。
- `.ps1`：兼容 Windows PowerShell 5.1（无 `&&`、`||`、`?.`、`??`）。含中文时存为 UTF-8 with BOM。需要中文路径参数时优先用环境变量传参。
- 删除类命令写明绝对路径，并在脚本里先校验目标存在且在预期目录内。
- 编辑 hook 会自动检查行尾、BOM 和 ASCII 约束，报错先修。
