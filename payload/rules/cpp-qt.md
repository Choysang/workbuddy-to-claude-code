# C++/Qt 规则（读写 C++/Qt 文件时生效）

- `QString::toDouble()` / `toInt()` 必须传 `bool *ok` 并检查。失败返回 0，而 0 常是合法值（如方位角）。
- 数据库事务：`commit()` 失败必须 `rollback()` 并 return，禁止继续提示"成功"。事务内禁止 `processEvents()`。
- 数千行的大文件：禁止重排格式，禁止改行尾（保持原样），只做定点修改。
- 每次修改后增量构建，再跑相关测试；通过再继续。沙箱里 cmd.exe 不可用，不能走 `vcvarsall.bat`，用项目已有的构建配方（如有对应技能先加载）。
- 注意生命周期：lambda 捕获 `this` 的悬空、QObject 父子所有权、静态析构顺序、跨线程信号槽的连接类型。
- 不引入新依赖，不改编译器/Qt 版本设置，除非用户要求。
